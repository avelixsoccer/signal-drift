# Сбор сигнала

Заглушка «страница в разработке» с фоновой анимацией дрейфующего облака частиц на Three.js: узлы медленно вращаются, покачиваются и соединяются линиями-«созвездием», когда сближаются, с лёгким параллаксом от курсора.

Нижняя строка статуса показывает реальные данные: время с момента открытия страницы, число частиц и текущее число активных связей.
